Running the Programs

1. Clone the repository:
   
   "git clone https://github.com/otiatojoseph44-beep/Python-assignments.git"

2. Navigate into the repository:
   
   "cd Python-assignments"

3. Run a Python file:
   
   "python filename.py"
   
   Alternatively:
   
   "python3 filename.py"

Replace "filename.py" with the name of the program you want to execute.
